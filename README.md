# EventOps — Event Management & Planning Dashboard (CMPA 4304)

## Overview
A centralized event management and task coordination web application built with Python, Flask, SQLite, and Bootstrap for independent event organizers and small event teams.

## How to Run
1. Open this repository in **GitHub Codespaces** (`Code` > `Codespaces` > `Create codespace on main`) or clone locally.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
3. Launch the application: python app.py
4. Open the forwarded port 5000 URL in your browser to view the dashboard pre-loaded with sample events and tasks.
